# Hotstar public catalogue diagnostic

Source: https://github.com/SumitMakariye/Hotstar-Data-Analysis-Using-Python/blob/main/hotstar.csv (Kaggle-derived historical catalogue; repository MIT license). Only factual public ID, type and title fields retained. Conflicting IDs excluded. This is not a current or episode-level catalogue. Numeric path tokens are matched locally; query parameters and signed URLs are never transmitted. Matches are unverified diagnostic candidates, not Trakt identities.
