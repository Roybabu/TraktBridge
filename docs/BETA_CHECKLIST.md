# v0.98.0 physical-device beta checklist

Record device, Android version, app version, pass/fail and reproduction steps. Do not attach account credentials or private playback history.

- Install over the previous signed APK; verify existing history is preserved.
- Verify notification listener and accessibility opt-in, pause and resume.
- Play a movie and two distinct episodes; validate sampled time, interruption recovery and review.
- Try wrong-account sync and an interrupted upload; verify no duplicate submission.
- Exercise airplane mode, poor network and rate limits.
- Verify encrypted backup export, merge and corrupted backup rejection.
- Check TV D-pad focus, large fonts and translated navigation.
- Test device credential lock, external links and privacy controls.
- Run at least one extended playback session; record battery and memory observations.
- Report crashes, ANRs and usability problems via beta feedback.

No device results are asserted until testers actually execute and record them.
