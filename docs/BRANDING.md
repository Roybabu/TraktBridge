# TraktBridge branding (0.171.0)

Native vector identity: interlocking violet and teal bridge shapes around a white playback triangle on a dark background. Android adaptive launcher icon, Android 13+ monochrome themed icon, in-app header and 320×180 Android TV banner. All assets are vector XML and do not require image downloads.

Haptic feedback is enabled by default on touch devices, optional in Settings, respects the platform haptic setting and device support, and is suppressed in TV mode. Uses native View.performHapticFeedback without vibration permissions. Covered: shared Compose navigation, actions, title cards, live dashboard, device management, master-detail selection and common native action buttons/choice dialogs. Some Android system dialogs and legacy widgets use their own platform feedback. Physical hardware validation remains required.
