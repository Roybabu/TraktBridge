# Compose migration inventory (0.138.0)

Migrated: app header, phone/tablet navigation, home summaries, TV home, library/review toolbars, title summary, loading and empty states, live playback, device center and mirrored history. Native views remain for the shell, settings, legacy catalogue and history cards, analytics/calendar, account/approval dialogs, QR and system integrations. They are retained to preserve behavior until feature-specific migration and accessibility regression coverage are available. Full Compose migration is not complete.
