# Settings organization (v0.178.0)
Compact grouped settings rows replace the long stack of filled action buttons. Connected Devices has one pairing entry, inline paired identities, separately consented playback/history/control sharing, and a nested advanced network/maintenance menu. Pairing still requires signed invitations, PIN verification and mutual approval. Tracking has one on/off switch, one app picker, and single entries for optional title detection and app-activity fallback. Other categories use related groups. Existing preferences, permissions, signing and Trakt upload consent are unchanged. Instrumentation checks category navigation and duplicate controls.
